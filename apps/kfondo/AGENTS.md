# 비용과 요청 처리

- 개발과 설계에서 Vercel Fluid Compute 비용 절감을 우선한다. 성능이나 사용성과 비용이 실제로 충돌하면 선택지와 영향을 사용자에게 설명하고 논의한다.
- 공개 페이지는 가능한 한 정적 CDN 규칙과 캐시로 제공한다. `proxy.ts`/`middleware.ts` 및 같은 역할의 Routing Middleware를 사용하지 않는다. 인증과 세션 갱신은 필요한 서버 경로 안에서 처리한다.
- 언어는 URL로 결정하고, 브라우저 언어 감지와 언어 제안은 페이지가 표시된 뒤 클라이언트에서만 처리한다.
- 관리자 응답은 캐시하지 않는다. 인증·권한 검증은 유지하고 세션 갱신은 필요한 관리자 인증 경로에서 처리한다.
- 사용자 설명과 새 코드 주석에는 한자를 쓰지 않고 한국어로 작성한다.
